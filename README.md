# World Explorer

World Explorer is a Next.js application that allows users to explore countries around the world using real API data.

## Features

- View list of countries
- Search countries by name
- Filter countries by region
- View detailed information about each country
- Dynamic routing for country pages
- Server and client components
- Data fetching from REST Countries API
- Responsive design

## Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- REST Countries API

## API Used

https://restcountries.com/v3.1/all  
https://restcountries.com/v3.1/alpha/[code]

## Pages

- / → Home page
- /countries → Countries list
- /countries/[code] → Country details page
- /search → Search countries
- /about → About page
